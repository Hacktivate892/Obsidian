## About

**Obsidian Browser** is an open-source desktop web browser designed to deliver a simple, lightweight browsing experience with privacy in mind.

Powered by Qt WebEngine, Obsidian uses Chromium-based rendering to display modern websites through a Python desktop application.

## Features

| Feature | Description |
|---|---|
| 🌐 Desktop Browsing | Browse websites in a dedicated desktop application. |
| ⚡ Lightweight | Built with Python and PyQt6. |
| ◈ Chromium Rendering | Display modern websites using Qt WebEngine. |
| 🔒 Privacy-Focused | Designed with privacy as a core goal. |
| 💻 Open Source | Available for permitted personal and educational use under the project license. |

## Requirements

Before installing, ensure you have the following:

- **Python 3**
- **PyQt6**
- **PyQt6-WebEngine**

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/Hacktivate892/Obsidian.git
```

### 2. Navigate to the project directory

```bash
cd ObsidianOS
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Launch Obsidian

```bash
python browser.py
```
